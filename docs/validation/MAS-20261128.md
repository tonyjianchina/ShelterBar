## 首次安装与 GUI 边界

新增/更新的用例覆盖空偏好、已保存空集合、首轮空/部分/完整扫描、晚到图标、授权后重扫、应用重启、只恢复既有布局、手动收纳和放回。通过单元测试验证不会因为「发现」图标而替用户收纳。

为避免干扰前台 Grok Bot 和可能的并行工作，本次保持 CLI 操作，没有启动 ShelterBar 或 GUI 自动化。`display-state.log` 的只读查询仅枚举到 **1 块内置 Retina 屏，1512×982 逻辑点、2×**；与任务提到的三屏连接状态不同，未擅自切换显示设置。

**真实收纳、恢复、点开原菜单，以及三屏逐一操作均待补。** 当前也没有运行沙盒功能实测；本分支明确阻止了该包产生，不能把配置中的 sandbox=true 说成通过了沙盒验收。
