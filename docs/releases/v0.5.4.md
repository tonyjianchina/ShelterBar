# ShelterBar v0.5.4 预览版 · build 19

适用于 **macOS 26.0 及以上、Apple Silicon（M1 及更新芯片）**。

## 本次更新

- 修复 macOS 26 合成菜单栏窗口发现，以及移动动画和辅助功能坐标不同步引起的收纳失败；忽略未参与操作的失效条目。
- 可见菜单栏入口与收起占位项分离，收起前验证入口所在安全区域。无法保留入口时保持展开，不保存失败的收纳结果。
- 改善浅色和深色收纳栏的图标对比度，保留灰阶细节、透明度和彩色小标记；彩色为主的图标不改色。
- 保留辅助功能授权后立即询问可选屏幕录制的引导，以及拖到 Applications 的 DMG 安装方式。
- 发布打包不再依赖 Finder 窗口自动化，并验证安装窗口的图标位置与背景引用。

## 下载与安装

- [DMG 安装包](https://github.com/tonyjianchina/ShelterBar/releases/download/v0.5.4/ShelterBar-0.5.4-macos-arm64.dmg)
- [ZIP 安装包](https://github.com/tonyjianchina/ShelterBar/releases/download/v0.5.4/ShelterBar-0.5.4-macos-arm64.zip)
- [SHA256SUMS](https://github.com/tonyjianchina/ShelterBar/releases/download/v0.5.4/SHA256SUMS)

打开 DMG，将 ShelterBar 拖到 Applications，然后推出安装盘，从“应用程序”打开。
应用显示在顶部菜单栏，不显示 Dock 图标。辅助功能权限为必需，屏幕录制仅用于读取原始状态图标，可拒绝并使用占位图标。

这是 **ad-hoc 签名、未经过 Apple 公证** 的预览版，不是 Developer ID 签名的正式版。如果系统阻止首次打开，请核对来源与 SHA256 后，按 [Apple 官方说明](https://support.apple.com/zh-cn/102445) 使用系统提供的“仍要打开”选项；不要关闭系统安全策略。升级后可能需要重新授权。

## 验证与已知限制

- 96 项自动化测试通过，覆盖权限串联、收起入口保护、图标对比度与既有收纳逻辑。
- 本机构建期间的原生面板截图确认 Shadowrocket、Muse、ChatGPT 在浅色背景下可辨认；不等于所有第三方图标、顶部入口交互和多显示器兼容性均已验证。
- DMG 和 ZIP 均检查包内版本、可执行文件一致性与签名完整性，DMG 检查拖拽安装布局，两个下载包提供 SHA256。
- 时钟、控制中心等系统固定项目及无可访问辅助功能条目的图标不支持管理；请避免同时运行其他菜单栏管理工具。
- 图标快照只缓存在内存中；读取失败时保留上次图像或占位图标，状态可能延迟更新。不采集音频、不录制视频、不保存或上传截图。

更多安装与验证说明见 [发布指南](https://github.com/tonyjianchina/ShelterBar/blob/v0.5.4/docs/RELEASE.md)。
