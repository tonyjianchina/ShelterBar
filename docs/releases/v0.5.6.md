# ShelterBar v0.5.6 预览版 · build 21

支持 **macOS 26.0 及以上、Apple Silicon（M1 及更新芯片）**。

## 本次修复

- 修复点击“授予输入权限”后没有可见反馈的问题。macOS 未弹出授权框且输入权限仍不可用时，自动打开对应的系统权限设置页。
- 在收纳栏显示授权指引；设置页打开失败时明确提示手动开启辅助功能与输入监控。列表没有 ShelterBar 时，提示通过“＋”添加应用。
- 首次请求后，手动点击仍可重新发起授权；后台轮询不会反复打开系统设置。已完整授权时不再请求。
- 保留辅助功能、输入监听和事件发送三项完整权限检查，缺少任何一项都不会开始拦截鼠标。完整输入权限生效后，继续询问可选的屏幕录制权限。
- 保留既有拖拽安装盘、菜单栏入口保护、图标对比度及原生窗口发现修复。

## 下载与安装

- [DMG 安装包](https://github.com/tonyjianchina/ShelterBar/releases/download/v0.5.6/ShelterBar-0.5.6-macos-arm64.dmg)
- [ZIP 安装包](https://github.com/tonyjianchina/ShelterBar/releases/download/v0.5.6/ShelterBar-0.5.6-macos-arm64.zip)
- [SHA256SUMS](https://github.com/tonyjianchina/ShelterBar/releases/download/v0.5.6/SHA256SUMS)

打开 DMG，将 ShelterBar 拖到 Applications，推出安装盘，再从“应用程序”打开。根据引导，在“系统设置 → 隐私与安全性”中开启辅助功能和输入监控；屏幕录制仅用于读取原始菜单栏图标，可以拒绝或稍后开启。授权必须由用户完成。

这是 **ad-hoc 签名、未经过 Apple 公证** 的预览版，不是 Developer ID 签名的正式版。升级或重新签名后，macOS 可能要求重新授权。若系统阻止首次打开，请核对来源与 SHA256 后，按 [Apple 官方说明](https://support.apple.com/zh-cn/102445) 使用系统提供的“仍要打开”选项；不要关闭系统安全策略。

## 验证与限制

- 107 项自动化测试全部通过，覆盖系统静默拒绝、重复点击、设置页打开失败、部分授权及原有收纳与事件保护逻辑。
- 本机实际验证了启动和点击按钮后进入辅助功能设置，以及收纳栏中的可见提示；没有替用户开启隐私权限，也不将设置页导航等同于完整授权验收。
- DMG 与 ZIP 校验版本、arm64 架构、签名完整性、可执行文件一致性及安装盘布局，并提供 SHA256 校验值。
- 第三方图标、刘海屏及多显示器兼容性仍需实际验证；请避免同时运行其他菜单栏管理工具。

更多安装与验证说明见 [发布指南](https://github.com/tonyjianchina/ShelterBar/blob/v0.5.6/docs/RELEASE.md)。
