# ShelterBar v0.5.12 预览版 · build 36

支持 **macOS 14 Sonoma 及以上、Apple Silicon（M1 及更新芯片）**。这是自签名、未经过 Apple 公证的早期预览版，暂不提供 Intel 版本。

## 本次更新

- 修复 macOS 27 上点击菜单栏图标后持续转圈或卡顿的问题。
- 新增自动更新，并在收纳栏的「更多」菜单中加入「检查更新」按钮。
- 修复部分菜单栏图标被宿主材质条替换后显示成实心方块的问题。
- 稳定标识的图标只在首次缺少缓存时读取；后续轮询和重启直接使用本地缓存，不再反复调用录屏。
- v0.5.11 及更早版本需要手动安装本版本一次；安装后，后续版本即可自动更新。

本版 196 项自动化测试全部通过。自动化测试和归档校验不等于所有第三方应用、显示器配置或 macOS 版本上的完整兼容性验证。

## 安装与权限

1. 打开 DMG，把 ShelterBar 拖进「应用程序」，然后推出磁盘。
2. 由于本版未经过 Apple 公证，首次打开若被拦截，请到「系统设置 → 隐私与安全性 → 安全性」点「仍要打开」。
3. ShelterBar 只在右上角菜单栏运行。按引导开启「辅助功能」和「输入监控」；「屏幕录制」仅用于显示原始图标，可以拒绝或稍后开启。

**从 v0.5.11 及更早版本升级时，需要手动下载并覆盖安装 v0.5.12 一次。** 从本版本开始，后续版本可通过自动更新或收纳栏「更多」菜单中的「检查更新」安装。

从 v0.5.6 或更早的 ad-hoc 签名版本升级时，需要重新授权一次。v0.5.7 及之后版本使用同一固定自签名身份，正常覆盖安装会保留授权。

更多安装、签名验证与已知限制见 [发布指南](https://github.com/tonyjianchina/ShelterBar/blob/v0.5.12/docs/RELEASE.md)。
