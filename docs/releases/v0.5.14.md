# ShelterBar v0.5.14（Build 38）正式版

本版把首次安装与打开的关键步骤直接放进 DMG 安装窗口，打开安装盘即可看到完整中文引导。

## 更新内容

- **拖到 Applications**：安装窗口第一步清楚展示 ShelterBar 与「应用程序」文件夹，直接拖入即可安装。
- **第一次打开先放行**：如果 macOS 提示无法打开，在「系统设置 → 隐私与安全性」底部点「仍要打开」，再确认打开。
- **按提示开启权限**：辅助功能和输入监控为必需；屏幕录制仅用于读取原始菜单栏图标，可以稍后开启。
- 调整安装窗口大小与图标位置，确保图标、名称和三步文字完整显示。
- 官网与下载说明改为正式版表述，并统一指向 v0.5.14。

## 安装与升级

- 支持 macOS 14 Sonoma 及以上、Apple Silicon（M1 及更新芯片）；暂不提供 Intel 安装包。
- 打开 DMG，把 ShelterBar 拖进 Applications，再从访达「应用程序」中双击 ShelterBar。若被系统拦下，先关闭提示，再到「系统设置 → 隐私与安全性 → 安全性」点击「仍要打开」并确认。
- ShelterBar 只在菜单栏运行，没有 Dock 图标或普通窗口；打开后点击右上角收纳箱图标，按引导授权。
- **v0.5.12 / v0.5.13 用户**可在本版本公开发布后通过自动更新或「更多 → 检查更新」升级。默认启动约 5 秒后检查，此后每 6 小时检查；需应用运行、网络可用、未禁用自动更新且安装目录可写。
- **v0.5.11 及更早版本**需手动覆盖安装一次。这些版本没有内置更新器。
- 沿用固定的 ShelterBar Self-Signed 证书，正常升级保留布局、图标缓存和权限；v0.5.6 及更早 ad-hoc 版本需重新授权一次。

## 验证与已知限制

- 合并后完整自动化回归：216 项测试通过（184 项应用测试、32 项核心测试）。
- 发布包已通过 arm64 架构、0.5.14 / Build 38、固定证书及 designated requirement、DMG 元数据、ZIP 解压和 SHA256 检查；Finder 实际挂载截图确认三步文字完整，图标和名称没有遮挡说明。
- 使用 v0.5.13 原始更新器代码对真实新 ZIP 验证：草稿不会进入更新候选；公开后无需 pre-release 标记即可选中；从 Build 37 到 38 的校验和暂存通过，验证过程没有执行替换 helper。
- 辅助功能与输入监控为必需；屏幕录制可选，仅读取严格匹配的单个菜单栏图标，不录音、不录像、不保存整屏截图，也不上传图像。
- 系统固定项目及部分未提供辅助功能接口的第三方图标无法管理。macOS 27 下同一应用的多个图标不能逐个独立收纳。刘海屏、多显示器和各类第三方应用仍需实际兼容性验证。
