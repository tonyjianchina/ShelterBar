# ShelterBar v0.5.7 预览版 · build 22

支持 **macOS 26.0 及以上、Apple Silicon（M1 及更新芯片）**。

## 重要：签名方式变更（需重新授权一次）

- 从本版起，ShelterBar 使用固定的自签名证书 **“ShelterBar Self-Signed”** 签名，不再使用 ad-hoc 临时签名。之后的版本都用同一证书签名，**升级后会保留辅助功能、输入监控和屏幕录制授权**。
- 从 v0.5.6 及更早版本升级时，由于签名身份变化，需要**重新授予一次**这三项权限。如果“系统设置 → 隐私与安全性”的列表里已有旧的 ShelterBar，先把它关闭再打开，或移除后重新添加。
- 仍**未经过 Apple 公证**。第一次打开会被系统拦下，需要在“系统设置 → 隐私与安全性”中点击“仍要打开”，步骤见下方“安装与第一次打开”。

## 本次修复与改进

- **图标对比度**：白色单色图标在收纳栏中不再看不清；浅色彩色图标会加一层对比底衬，深浅外观下都可辨认。
- **全屏与自动隐藏菜单栏**：全屏应用或菜单栏自动隐藏时，收纳不再失败。
- **单个失败不再全部展开**：某个图标拒绝移动时，只提示并保留这一个图标，其余已收纳图标保持收起。
- **刘海屏**：临时放出和移动图标时避开刘海区域；空间不足时给出提示，而不是展开整排菜单栏。
- **点击收纳栏图标打开菜单**：只把被点击的图标临时放到收纳栏正下方并打开它的菜单；菜单关闭后，经过短暂宽限期自动收回。
- **光标复位与崩溃恢复**：每次合成拖动后光标回到原位。临时放出前会先记录待恢复状态；如果中途崩溃或退出，下次启动时会自动收回。
- **图标磁盘缓存**：已收纳图标的小尺寸 PNG 缓存到本机 `~/Library/Application Support/ShelterBar/IconCache/`，重启后直接显示，不再出现“?”占位。图标移回菜单栏后即删除对应缓存，缓存从不上传。
- **延续 v0.5.3–v0.5.6 的修复**：独立的固定宽度入口与收纳边界（适配 macOS 26 合成菜单栏）、刘海处的入口避让与边界回退、输入权限门（缺权限时不拦截点击）、“授予输入权限”按钮跳转系统设置、诊断工具与图形化安装盘全部保留。浅灰阶单色图标沿用随外观自适应的处理，并在重启后从缓存恢复时保持自适应。
- **外接显示器定位**：修复 24 pt 高的外接显示器菜单栏上，入口与收纳边界因图标下移 3 pt 而无法定位、导致点击后整排展开的问题。
- **屏幕录制引导**：辅助功能一生效就立即询问屏幕录制，不再等到输入监控等三项输入权限全部生效。鼠标拦截仍要求三项输入权限齐全。

### 安装与第一次打开

1. **安装**：打开 DMG，把 ShelterBar 拖进「应用程序」（Applications）文件夹，然后推出磁盘。
2. **第一次打开**：在访达的「应用程序」文件夹里双击 ShelterBar（刚安装时，聚焦搜索可能要过几分钟才能搜到）。ShelterBar 没有经过 Apple 公证，系统会拦下并提示无法验证，先点「完成」关闭提示；然后打开「系统设置 → 隐私与安全性」，往下滚到「安全性」部分，点 ShelterBar 旁边的「仍要打开」，再确认一次「打开」（可能需要输入登录密码）。macOS 15 起，右键「打开」已不能绕过这一步。
   - 高级用户也可以在核对 SHA256 后，在终端运行 `xattr -dr com.apple.quarantine /Applications/ShelterBar.app`，再双击打开。
   - 每次下载只需放行一次。以后下载新版本覆盖安装时，如果系统再次拦下，按同样步骤放行即可；辅助功能等授权会保留，不用重新授权（从 v0.5.6 及更早版本升级除外，需重新授权一次）。
3. **打开之后**：ShelterBar 只在菜单栏运行，没有 Dock 图标，也没有普通窗口——请留意屏幕右上角菜单栏里新出现的收纳箱图标，点它即可展开收纳栏。首次启动时，收纳栏会自动在图标下方展开，并按引导请求授权：先是「辅助功能」和「输入监控」（必需），辅助功能生效后再请求「屏幕录制」（可选，只用于显示原始图标）。

请先确认下载来源与 SHA256；不要关闭 Gatekeeper。屏幕录制拒绝或稍后开启都不影响收纳，收纳栏会使用占位图标。授权必须由用户完成。

## 已知问题

- 点击收纳栏图标打开菜单时，光标可能短暂闪烁。
- 菜单关闭后，图标约 1.5 秒才收回收纳区。
- 当前方案依赖 macOS 26 的菜单栏实现，macOS 27 预计需要新的实现方式。
- 第三方图标与多显示器组合仍可能存在差异；请避免同时运行其他菜单栏管理工具。
