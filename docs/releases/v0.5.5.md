# ShelterBar v0.5.5 预览版 · build 20

支持 **macOS 26.0 及以上、Apple Silicon（M1 及更新芯片）**。

## 本次修复

- 修复权限切换、重新安装或临时签名变化后，鼠标可以移动但全局点击和窗口切换可能失效的问题。
- ShelterBar 只有在辅助功能、输入监听和事件发送能力全部可用时才安装或恢复鼠标事件拦截。
- 运行中权限失效会立即取消当前拖动并放行物理鼠标事件，不再留下“按下被吞、松开无法完成”的半授权状态。
- 权限引导和界面明确提示“辅助功能”和“输入监控”均为拖动收纳所必需；屏幕录制仍为可选，只用于读取原始菜单栏图标。
- 保留 v0.5.4 的原生窗口发现、菜单栏入口保护、图标对比度和无需 Finder 自动化的 DMG 打包改进。

## 下载与安装

- [DMG 安装包](https://github.com/tonyjianchina/ShelterBar/releases/download/v0.5.5/ShelterBar-0.5.5-macos-arm64.dmg)
- [ZIP 安装包](https://github.com/tonyjianchina/ShelterBar/releases/download/v0.5.5/ShelterBar-0.5.5-macos-arm64.zip)
- [SHA256SUMS](https://github.com/tonyjianchina/ShelterBar/releases/download/v0.5.5/SHA256SUMS)

打开 DMG，将 ShelterBar 拖到 Applications，然后推出安装盘，从“应用程序”打开。首次运行请在“系统设置 → 隐私与安全性”中同时允许 ShelterBar 的“辅助功能”和“输入监控”。升级或重新签名后，macOS 可能要求重新授权。

这是 **ad-hoc 签名、未经过 Apple 公证** 的预览版，不是 Developer ID 签名的正式版。如果系统阻止首次打开，请核对来源与 SHA256 后，按 [Apple 官方说明](https://support.apple.com/zh-cn/102445) 使用系统提供的“仍要打开”选项；不要关闭系统安全策略。

## 验证与已知限制

- 99 项自动化测试全部通过，覆盖完整输入权限门、启动时缺权、拖动中撤权、合成事件绕过和既有收纳逻辑。
- DMG 和 ZIP 均检查包内版本、arm64 架构、签名完整性、可执行文件一致性和安装盘布局，并提供 SHA256。
- 本次修复可阻止 ShelterBar 在半授权状态下继续吞掉鼠标事件；macOS 权限面板和第三方输入工具仍由系统控制。
- 时钟、控制中心等系统固定项目及无可访问辅助功能条目的图标不支持管理；请避免同时运行其他菜单栏管理工具。

更多安装与验证说明见 [发布指南](https://github.com/tonyjianchina/ShelterBar/blob/v0.5.5/docs/RELEASE.md)。
