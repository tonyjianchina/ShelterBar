# ShelterBar v0.5.13（Build 37）预览版

本版减少刷新和点击时的主线程等待，让提示信息不再挡住图标，并减少重复的更新下载。

## 变化

- 已缓存图标直接读取，不再为了展示缓存图标向第三方应用查询辅助功能标题。旧缓存迁移时仍按需读取。
- 打开原生菜单的 AXPress 请求在专用串行队列执行，保留原有超时、菜单检测与位置校验。
- 提示文字和可选录屏授权引导使用独立区域，收纳图标始终保留；支持空格、回车及辅助功能激活图标。
- 后台检查更新不会覆盖操作提示。相同已验证发布资产复用检查结果，减少下载、解压和签名检查；新资产和手动重装仍完整验证。
- 继续保留图标持久缓存及失败缓存，后台轮询和重启不会为同一已缓存或已失败图标反复录屏。

## 安装与升级

- Apple Silicon（M1 及更新芯片），macOS 14 Sonoma 及以上；没有 Intel 安装包。
- **v0.5.12（Build 35 / 36）用户可自动升级**：启动约 5 秒后检查，此后每 6 小时检查一次。应用需运行、网络可用、未禁用自动更新且安装目录可写。也可点击“更多 → 检查更新”。
- **v0.5.11 及更早版本需手动覆盖安装一次**，这些旧版本没有内置更新器。
- 沿用固定的 ShelterBar Self-Signed 证书，正常升级保留已有布局、缓存和权限；v0.5.6 及更早 ad-hoc 版本需重新授权一次。

本预览版使用自签名证书，**没有 Developer ID 签名或 Apple 公证**。首次打开和权限说明见[安装指南](../RELEASE.md)。辅助功能、输入监控为必需；屏幕录制可选，仅用于首次读取尚未缓存的单个菜单栏图标。不采集音频，不录制视频，不保存整屏截图，不上传图像。

## 验证范围

合并后的完整自动化回归共 216 项通过（184 项应用测试 + 32 项核心测试）。发布流程还验证原生 SwiftUI fixture 渲染、DMG 布局与签名、ZIP 解压及 SHA256 校验。复用 v0.5.12 的原始更新器代码验证新包的版本选择、构建号、摘要、架构、签名和暂存安装步骤；不在验证过程中退出或替换用户正在运行的应用。

受控性能测试用于确认主线程不再承受模拟的第三方 IPC 等待，并不代表所有真实菜单的端到端耗时。第三方应用、多显示器、刘海屏与不同 macOS 版本仍需实际兼容性验证。

分支实验与测试证据见 [流畅度](../experiments/smoothness.md)、[收纳栏界面](../experiments/shelf-ui.md)、[更新检查](../experiments/feature-polish.md)。
