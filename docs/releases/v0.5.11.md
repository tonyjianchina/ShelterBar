# ShelterBar v0.5.11 预览版 · build 34

支持 **macOS 14 Sonoma 及以上、Apple Silicon（M1 及更新芯片）**。这是自签名、未经过 Apple 公证的早期预览版，暂不提供 Intel 版本。

## 本次更新

- 恢复并整合最新的菜单栏收纳能力，增强 macOS 27 菜单栏宿主、隐藏状态验证和状态图标捕获。
- 改进复合图形、透明背景和计数标记的图标识别；收纳栏菜单现在会显示当前版本与构建号。
- 修复首次申请输入权限时系统设置页与 macOS 原生权限弹窗同时打开的问题。现在只显示权限弹窗，请从弹窗点「打开系统设置」；若系统没有再次显示弹窗，可使用收纳栏里的独立「打开设置」按钮。
- 忽略已经离开菜单栏的失效点击区域，避免误拦截普通桌面点击。
- 当系统或用户主动禁用事件监听时，不再根据可能过期的权限状态立即重启监听。

本版 181 项自动化测试全部通过。自动化测试和归档校验不等于所有第三方应用、显示器配置或 macOS 版本上的完整兼容性验证。

## 安装与权限

1. 打开 DMG，把 ShelterBar 拖进「应用程序」，然后推出磁盘。
2. 由于本版未经过 Apple 公证，首次打开若被拦截，请到「系统设置 → 隐私与安全性 → 安全性」点「仍要打开」。
3. ShelterBar 只在右上角菜单栏运行。按引导开启「辅助功能」和「输入监控」；「屏幕录制」仅用于显示原始图标，可以拒绝或稍后开启。

从 v0.5.6 或更早的 ad-hoc 签名版本升级时，需要重新授权一次。v0.5.7 及之后版本使用同一固定自签名身份，正常覆盖安装会保留授权。

更多安装、签名验证与已知限制见 [发布指南](https://github.com/tonyjianchina/ShelterBar/blob/v0.5.11/docs/RELEASE.md)。
